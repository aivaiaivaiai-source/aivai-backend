## Запчасти

- Rename отображаемого имени «Автозапчасти» → «Запчасти»; **slug `transport-auto-parts` сохранить**.
- UX: Для какого транспорта → Раздел → Название детали → совместимость (поля одного экрана).
- Группы: см. задание §6 (включая Кузов и наружные детали как parent для кузовных детей; Рабочая гидравлика; Рабочие органы; Электропривод).
- Свет только в Оптика; звук только в Аксессуары → Автозвук.
- Vehicle-specific «запчасти для X» → общая база + применимость.
